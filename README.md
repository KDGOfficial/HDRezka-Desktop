# HDREZKA Desktop

Неофициальный полнофункциональный настольный клиент **HDREZKA** для **Windows 10 и Windows 11**.

Приложение разработано как самостоятельный Desktop-клиент без использования Electron, NW.js или простого WebView-сайта, обеспечивая максимальную производительность, минимальное потребление оперативной памяти и нативную интеграцию с Windows.

---

## 🚀 Основные особенности

- **Современный премиальный дизайн**: Вдохновлен лучшими чертами Netflix, Apple TV и Кинопоиска в фирменной темной палитре (`#101114`, `#17181D`, `#1D1F26`, `#E50914`).
- **Полнофункциональный видеоплеер**:
  - Кастомный интерфейс без стандартных элементов браузера
  - Поддержка HLS (m3u8) и HTML5 Video
  - Выбор качества стрима (от 360p до 1080p Ultra)
  - Выбор озвучки / переводчика (Дубляж, HDRezka Studio, LostFilm, Кубик в кубе и др.)
  - Поддержка нескольких дорожек субтитров (VTT)
  - Регулировка скорости воспроизведения (0.5x – 2x)
  - Полоса перемотки с буферизацией и превью времени
  - Автоматический переход к следующей серии
  - Управление громкостью колесиком мыши
  - Горячие клавиши (`Space`, `Left`/`Right`, `Up`/`Down`, `F`, `M`, `Esc`)
- **Медиатека и каталог**:
  - Разделы: Фильмы, Сериалы, Мультфильмы, Аниме, Коллекции
  - Фильтры по жанрам, годам выпуска, странам, минимальному рейтингу
  - Сортировка по популярности, рейтингу, дате выхода, алфавиту
  - Пагинация и быстрый сброс фильтров
- **Продвинутый поиск**:
  - Быстрый поиск в реальном времени с автодополнением
  - Локальная история запросов и популярные теги
- **Детальные страницы контента**:
  - Большой фон (backdrop), постер, метаданные (рейтинг, жанры, длительность, год, страна)
  - Актерский состав и режиссеры
  - Полное описание с возможностью раскрытия
  - Селектор сезонов и серий с карточками серий для сериалов
  - Блок рекомендаций и похожих тайтлов
- **Локальная база данных (SQLite)**:
  - Хранение избранного, истории просмотров, прогресса серий и настроек в системной папке данных Tauri (`AppData`)
  - Пользовательские коллекции (создание, удаление, экспорт/импорт)
  - Запоминание точной секунды и процента просмотра для быстрого продолжения
- **Система зеркал HDRezka**:
  - Поддержка предустановленных и пользовательских зеркал
  - Проверка доступности и измерение задержки (ping / latency)
  - Переключение активного зеркала «на лету»
  - Безопасное декодирование потоков CDN HDRezka на стороне Rust
- **Кастомный оконный фрейм Windows**:
  - Собственная верхняя панель (TitleBar) с кнопками «Свернуть», «Развернуть/Восстановить», «Закрыть»
  - Возможность перемещения окна за заголовок (drag-region)

## 🛠 Технологический стек

### Desktop Framework
- **Tauri 2**: современная альтернатива Electron с безопасной архитектурой на Rust и WebView2.
- **WebView2**: системный движок Windows (Chromium-based), обеспечивающий быстрый рендеринг и низкое потребление RAM.

### Frontend
- **React 19**
- **TypeScript**
- **Vite 8**
- **Tailwind CSS 4**
- **Zustand 5** (управление состоянием навигации, плеера, настроек и уведомлений)
- **Framer Motion**
- **Lucide React** (набор современных иконок)
- **HLS.js** (воспроизведение адаптивных видеопотоков)

### Backend
- **Rust (2021 edition)**
- **SQLite (rusqlite bundled)** — надежное локальное хранилище данных без внешних СУБД
- **Tokio** — асинхронный рантайм
- **Reqwest (rustls-tls)** — быстрый HTTP-клиент для работы с зеркалами
- **Scraper** — надежный HTML/CSS парсер структуры сайта
- **Base64 & Regex** — алгоритм деобфускации CDN-потоков HDRezka (`clear_trash`)

## 💻 Установка и запуск

### Предварительные требования

1. **Node.js** (v20 или новее)
2. **Rust** (toolchain `x86_64-pc-windows-msvc`)
3. **Microsoft C++ Build Tools** или **Visual Studio 2022 Community** (C++ Desktop Development)

### Запуск в режиме разработки

```bash
# Запуск интерфейса и бэкенда в режиме разработки Tauri
npm run tauri dev
```

Для автономной разработки веб-части в браузере:
```bash
npm run dev
```

### Сборка готового приложения для Windows

```bash
# Сборка инсталляторов .exe и .msi
npm run tauri build
```

Готовые дистрибутивы будут созданы в папке:
`src-tauri/target/release/bundle/nsis/` (`HDREZKA-Setup.exe`)
`src-tauri/target/release/bundle/msi/` (`HDREZKA.msi`)

## 🔒 Безопасность и хранение данных

- Пользовательские данные (история, избранное, пользовательские коллекции, токены зеркал) сохраняются в локальной базе данных SQLite в каталоге:
  `%APPDATA%\com.hdrezka.desktop\hdrezka.db`
- При обновлении или переустановке приложения локальная база данных сохраняется автоматически.
- Доступна функция экспорта/импорта настроек и коллекций в формате JSON через вкладку «Настройки».
