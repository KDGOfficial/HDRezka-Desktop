## 📖 О проекте

**HDREZKA Desktop** — это автономное настольное приложение для комфортного просмотра фильмов, сериалов, мультфильмов и аниме с популярного онлайн-кинотеатра HDRezka. 

Приложение спроектировано с акцентом на кинематографичный пользовательский опыт в стиле современных стриминговых сервисов (Netflix / Apple TV), без рекламы из браузера, с полной поддержкой аппаратного ускорения, локальным кэшированием и гибким видеоплеером.

## ✨ Ключевые возможности

### 🎬 Каталог и навигация
- **Главная витрина**: адаптивный Hero-баннер с новинками, динамические слайдеры «Популярное», «Новинки», «Фильмы», «Сериалы» и «Рекомендации».
- **Разделы каталога**: Фильмы, Сериалы, Мультфильмы, Аниме.
- **Глубокая фильтрация**: сортировка по популярности, дате обновления, рейтингу IMDb/Кинопоиск, фильтры по жанрам и годам выпуска.
- **Информативные карточки**: отображение рейтинга, года, категорий и статуса онгоингов (сезон/серия).

### ⚡ Быстрый и расширенный поиск
- **Мгновенный Live-поиск**: подсказки и результаты прямо во время ввода запроса.
- **Расширенный поиск**: полноценная страница выдачи с пагинацией и детализацией.
- **История поиска**: сохранение последних запросов в локальной базе данных.

### 🍿 Кинематографичный видеоплеер
- **Потоковое воспроизведение HLS**: адаптивная подгрузка сегментов с минимальной задержкой буферизации.
- **Выбор качества**: от `360p` до `1080p Ultra` с автоматическим сохранением выбранного разрешения.
- **Выбор озвучки / переводчиков**: переключение между студиями дубляжа и закадрового перевода (HDRezka Studio, LostFilm, NewStudio, Дубляж и др.) без перезагрузки плеера.
- **Удобная навигация по эпизодам**: всплывающее меню сезонов и серий прямо поверх видео.
- **Контроль скорости**: от `0.5x` до `2.0x`.
- **Автоматическое запоминание позиции (Playback Resume)**: плеер сохраняет таймкод до секунды для каждого эпизода или фильма.
- **Автопереход**: автоматический запуск следующей серии по завершении текущей.

### 💾 Локальное хранилище данных (SQLite)
Вся история и пользовательские данные сохраняются локально на вашем компьютере с помощью легковесной SQLite (`sql.js` WebAssembly):
- **История просмотров**: детальный журнал с таймкодом и индикатором процента прогресса.
- **Избранное**: быстрый доступ к любимому контенту в один клик.
- **Пользовательские коллекции**: создавайте персональные тематические подборки с кастомными названиями и описанием.

### 🛡️ Умная работа с зеркалами и Fallback
- Автоматический пинг и проверка задержки (latency test) зеркал HDRezka.
- Возможность добавлять и менять пользовательские зеркала в меню настроек.
- Встроенный механизм **Fallback Data**: если зеркало временно недоступно или защищено Cloudflare anti-bot экраном, интерфейс не ломается и продолжает работать.

### 🌐 Мультиязычный интерфейс (i18n)
- Полная локализация приложения на **Украинский (Українська)**, **Английский (English)** и **Русский** языки.
- Мгновенное переключение языка в один клик в боковой панели или через страницу настроек.

### 🚀 Автообновление и CI/CD релизы через GitHub
- **Автоматическая сборка в CI/CD**: настроен GitHub Actions workflow (`.github/workflows/release.yml`), автоматически компилирующий дистрибутивы под Windows при создании тегов `v*` и прикрепляющий исполняемые файлы (`HDREZKA-Setup-<версия>.exe` и `HDREZKA-Portable-<версия>.exe`) к релизу.
- **Встроенная проверка обновлений**: автоматическая проверка свежих версий прямо из официального GitHub-репозитория при запуске приложения.
- **Интеллектуальная загрузка**: скачивание установщика в один клик с отображением шкалы прогресса, процентов и переданного объема данных; если файл еще формируется на CI/CD, приложение безопасно открывает страницу релиза в браузере.
- **Автоустановка**: мгновенный запуск установщика и перезапуск приложения в один клик.

## 🚀 Установка и запуск

### Предварительные требования
- [Node.js](https://nodejs.org/) версии **18.x** или новее
- Менеджер пакетов `npm`

### 1. Клонирование репозитория
```bash
git clone https://github.com/KDGOfficial/HDRezka-Desktop.git
cd HDRezka-Desktop
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Режим разработки
Запуск приложения в режиме разработки с поддержкой Hot Module Replacement (HMR):
```bash
npm run dev
```

### 4. Запуск тестов
```bash
npm test
```

## 📦 Сборка дистрибутива под Windows

Сборка оптимизированного релизного приложения выполняется с помощью `electron-builder`:

```bash
# Компиляция основного процесса и рендерера
npm run build

# Создание распакованной директории для проверки
npm run pack

# Сборка готового инсталлятора (.exe) и Portable-версии
npm run dist
```

Собранные файлы (`HDREZKA-Setup-0.0.47.exe` и `HDREZKA-Portable-0.0.47.exe`) появятся в папке `release/`.
